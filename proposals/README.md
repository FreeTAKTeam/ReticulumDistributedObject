# RDO Proposals

Proposed changes to RDO should be submitted as numbered Markdown documents using the following convention:

```text
RDO-0001-<short-name>.md
RDO-0002-<short-name>.md
```

A proposal should explain the problem, the proposed protocol change, compatibility effects, security effects, and whether the normative specification must change. Proposals are discussion documents and do not modify the protocol by themselves.

Accepted proposals may eventually modify the normative `SPECIFICATION.md`. A specification change should identify the accepted proposal and update the changelog and version as required.
